# SnakeID TH

เว็บแอปช่วยจำแนกชนิดงูเบื้องต้นสำหรับคนไทย ทำงานได้ 2 โหมด: ตอบคำถามลักษณะงู (ทำงานในเครื่อง ไม่ต้องต่อเน็ต) และอัปโหลดรูปถ่าย (ใช้ Google Gemini วิเคราะห์ผ่าน backend ของตัวเอง)

> ⚠️ เครื่องมือนี้ให้ข้อมูลเบื้องต้นเท่านั้น **ไม่ใช่การวินิจฉัยทางการแพทย์** ถูกงูกัดให้ไปโรงพยาบาลเสมอ

---

# ส่วนที่ 1: วิธีใช้งาน (สำหรับผู้ใช้ทั่วไป)

## หน้าแรก
เลือกได้ 4 อย่าง: ตอบคำถามลักษณะงู, อัปโหลดรูปถ่าย, ดูฐานข้อมูลงูทั้งหมด, และวิธีปฐมพยาบาลเบื้องต้น
ก่อนเริ่ม แนะนำให้เลือก "ภูมิภาค" ที่เจองู (เหนือ/อีสาน/กลาง/ตะวันออก/ใต้) ระบบจะจำค่านี้ไว้ใช้ครั้งถัดไป และใช้จำกัดขอบเขตชนิดงูที่เป็นไปได้ในพื้นที่นั้นให้แคบลง

## โหมดที่ 1: ตอบคำถามลักษณะงู
ตอบคำถามทีละข้อ (รูปร่างหัว, ลวดลาย, สี, แผ่แม่เบี้ยหรือไม่, มีแอ่งรับความร้อนหรือไม่, พบตอนกลางวัน/กลางคืน) แต่ละคำถามมีไดอะแกรมประกอบให้ดูว่าลักษณะที่ถามหมายถึงแบบไหน ถ้าไม่แน่ใจข้อไหนกดข้ามได้ ไม่ต้องเดา

ตอบครบทุกข้อแล้วระบบจะถามว่า **อยากอัปโหลดรูปเพิ่มเพื่อความแม่นยำขึ้นไหม** (ไม่บังคับ) — ถ้ามีรูปงูตัวนั้นจริงๆ แนะนำให้อัปโหลด เพราะระบบจะเอาทั้งคำตอบและรูปมาประกอบกันวิเคราะห์ ได้ผลแม่นกว่าใช้อย่างใดอย่างหนึ่ง ถ้าไม่มีรูปกด "ข้าม" เพื่อดูผลจากคำตอบอย่างเดียวได้เลย

ผลลัพธ์จะแสดง 3 อันดับที่เป็นไปได้มากที่สุด พร้อมเปอร์เซ็นต์ความมั่นใจ ระดับอันตราย ชื่อเซรุ่มแก้พิษ และอาการที่ควรสังเกต ถ้าอันดับ 1 มีเปอร์เซ็นต์ต่ำ หรือมีงูพิษคะแนนใกล้เคียงกับตัวที่ไม่มีพิษ ระบบจะเตือนให้สันนิษฐานว่าอันตรายไว้ก่อนเสมอ

## โหมดที่ 2: อัปโหลดรูปถ่าย
ถ่ายรูปหรือเลือกรูปงูจากคลังภาพได้เลย โดยไม่ต้องตอบคำถามก่อน ระบบจะส่งรูปไปวิเคราะห์และแสดงผลแบบเดียวกับโหมดคำถาม ถ้าโหมดนี้ขึ้นว่ายังใช้งานไม่ได้ ให้ใช้โหมดตอบคำถามแทนไปก่อน

ถ้ารูปที่ส่งไปไม่ตรงกับ 10 ชนิดในฐานข้อมูลหลักเลย ระบบอาจแสดงกล่อง "AI ประเมินเสริม" แยกต่างหาก ซึ่งเป็นการเดาจากความรู้ทั่วไปของ AI **ยังไม่ผ่านการตรวจสอบข้อมูลเซรุ่ม/ปฐมพยาบาลแบบเฉพาะเจาะจง** ให้ระวังเป็นพิเศษและไปโรงพยาบาลเสมอ

## ดูฐานข้อมูลงูทั้งหมด
เปิดดูรายละเอียดงูทั้ง 10 ชนิดในระบบได้โดยไม่ต้องตอบคำถามหรืออัปโหลดรูป เหมาะสำหรับศึกษาไว้ล่วงหน้า

## วิธีปฐมพยาบาล
ขั้นตอนปฐมพยาบาลเบื้องต้นเมื่อถูกงูกัด และเบอร์โทรฉุกเฉิน (1669 / ศูนย์พิษวิทยารามาธิบดี 1367) กดโทรออกได้ทันทีจากปุ่มในหน้านี้

## ข้อควรรู้
- ผลลัพธ์ทุกโหมดเป็นการ**คาดคะเน** ไม่ใช่การวินิจฉัย ห้ามใช้แทนคำแนะนำแพทย์
- ถูกงูกัดจริง ให้ไปโรงพยาบาลหรือโทร 1669 ทันที ไม่ต้องรอผลจากแอปนี้ก่อน
- ถ้าจำแนกไม่ได้ ให้สันนิษฐานว่าเป็นงูพิษไว้ก่อนเสมอ เพื่อความปลอดภัย

# ส่วนที่ 2: คู่มือสำหรับนักพัฒนา (สำหรับต่อยอด)

## โครงสร้างไฟล์
```
SnakeID_TH.html   หน้าเว็บทั้งหมด (HTML+Tailwind CDN+JS ในไฟล์เดียว, ไม่ต้อง build)
server.js         backend (Node/Express) เรียก Google Gemini Vision วิเคราะห์รูป
package.json      dependencies ของ backend
.env.example      ตัวอย่างไฟล์ตั้งค่า (คัดลอกเป็น .env แล้วใส่ GOOGLE_API_KEY)
```
`SnakeID_TH.html` ทำงานได้เองแบบ static ไม่ต้องมี backend ก็ใช้โหมดตอบคำถามได้ปกติ — backend จำเป็นเฉพาะโหมดอัปโหลดรูปเท่านั้น

## สถาปัตยกรรมคร่าวๆ
```
[ผู้ใช้] → เปิด SnakeID_TH.html (host ที่ไหนก็ได้ที่ serve static file เช่น GitHub Pages)
             │
             ├─ โหมดคำถาม/ฐานข้อมูล/ปฐมพยาบาล → คำนวณในเบราว์เซอร์ล้วนๆ ไม่มี network call
             │
             └─ โหมดอัปโหลดรูป → POST รูป (base64) ไปที่ API_ENDPOINT
                                     │
                                     ▼
                            [server.js บน Render/Railway/ฯลฯ]
                                     │  เก็บ GOOGLE_API_KEY ไว้ที่นี่เท่านั้น
                                     ▼
                          Google Gemini (ai.models.generateContent)
                                     │
                                     ▼
                      ตอบ JSON {predictions:[...], extra_guess?}
```

## แก้ไข/เพิ่มฐานข้อมูลงู
ข้อมูลงูอยู่ **2 ที่ที่ต้องแก้พร้อมกัน** เพราะ id ต้องตรงกัน:
1. `SNAKES` array ใน `SnakeID_TH.html` — ใช้แสดงผล คำนวณคะแนนโหมดคำถาม และแสดงหน้าฐานข้อมูล
   แต่ละตัวมี: `id, th (ชื่อไทย), sci (ชื่อวิทยาศาสตร์), venom (neuro/hemato/mild/none), danger (0-3), region (ภาคที่พบ), antivenom, desc, symptoms, tags`
   `tags` คือลักษณะที่ใช้จับคู่กับคำตอบในโหมดคำถาม (`hood, headShape, pattern, color[], pit, time`)
2. `SNAKE_REFERENCE` ใน `server.js` — คำอธิบายสั้นๆ ที่ส่งเข้า prompt ให้ Gemini เทียบกับรูป

**เพิ่มชนิดงูใหม่:** เพิ่ม object ใหม่ทั้งสองที่ด้วย `id` เดียวกัน ถ้าลืมเพิ่มที่ใดที่หนึ่ง โหมดนั้นจะจำแนกชนิดนั้นไม่ได้ (แต่อีกโหมดยังทำงานปกติ)

## แก้ไข/เพิ่มคำถามในโหมด wizard
แก้ที่ array `QUESTIONS` ใน `SnakeID_TH.html` แต่ละคำถามมี `key, w (น้ำหนักคะแนน), hard (true = ถ้าตอบขัดกับชนิดนั้นให้หักคะแนนแรง เหมาะกับลักษณะชี้ขาดเช่นแผ่แม่เบี้ย/มีแอ่งรับความร้อน), q (คำถาม), opts (ตัวเลือก แต่ละอันมี `icon` เป็น SVG/HTML สำหรับแสดงไดอะแกรมประกอบ)`
ถ้าเพิ่มคำถามใหม่ ต้องเพิ่ม key ที่ตรงกันใน `tags` ของงูทุกตัวใน `SNAKES` ด้วย ไม่งั้นคะแนนจะคำนวณผิด

การให้คะแนนอยู่ในฟังก์ชัน `score()` — คะแนนของแต่ละชนิด = ผลรวมน้ำหนักคำถามที่ตอบตรง หารด้วยน้ำหนักรวมทั้งหมดที่ตอบไป (ข้อที่กด "ไม่แน่ใจ" ไม่นับ)

## โหมดอัปโหลดรูป / การเชื่อม Gemini
- ตัวแปร `API_ENDPOINT` ใน `SnakeID_TH.html` ต้องชี้ไป URL ของ `server.js` ที่ deploy ไว้ (ดูวิธี deploy ด้านล่าง)
- `server.js` ใช้ `ai.models.generateContent` (ไม่ใช้ Interactions API เพราะยังเป็น Beta และมี breaking change บ่อย)
- ผลลัพธ์บังคับ schema ผ่าน `responseSchema` ให้ตรงรูปแบบ `{predictions:[{id,confidence}], extra_guess?}` เสมอ
- มีการ normalize confidence กันกรณี Gemini ตอบเป็นสัดส่วน 0-1 แทน 0-100 (ดูฟังก์ชันหลัง `if (!parsed.predictions...)`)
- `MODELS` array คือลิสต์โมเดลสำรอง ถ้าตัวแรกโควต้าหมด (HTTP 429) จะลองตัวถัดไปอัตโนมัติ ผ่านฟังก์ชัน `generateWithFallback()`
- ถ้าผู้ใช้ตอบคำถามมาก่อนแล้วค่อยอัปโหลดรูป (โหมด "refine") หน้าเว็บจะส่ง `answers` ไปด้วย และ `server.js` จะแปลงเป็นข้อความไทยผ่าน `ANSWER_LABELS`/`answersToText()` ใส่ใน prompt ให้ Gemini ใช้ประกอบกับรูป

### รัน backend ในเครื่อง
```bash
npm install
cp .env.example .env
# ใส่ GOOGLE_API_KEY ใน .env (ขอได้ที่ https://aistudio.google.com/apikey)
node server.js
```
ทดสอบว่ารันอยู่: `http://localhost:3001/health` ควรได้ `{"ok":true}`

### Deploy ขึ้นเว็บจริง
- หน้าเว็บ (static): GitHub Pages, Netlify, Vercel ก็ได้ — เป็นไฟล์ HTML เดี่ยว ไม่ต้อง build
- backend: ต้องเป็นที่รัน Node.js ได้ต่อเนื่อง เช่น Render, Railway, Fly.io — ตั้ง `GOOGLE_API_KEY` เป็น environment variable บนแพลตฟอร์มนั้น อย่าใส่ในโค้ดที่ push ขึ้น git
- Render free tier จะ sleep หลังไม่มีคนใช้ 15 นาที (cold start ~30-60 วิ) ถ้าต้องการความเร็วสม่ำเสมอให้พิจารณาแผนเสียเงิน
- อย่าลืมจำกัด `cors()` ใน `server.js` ให้เหลือเฉพาะโดเมนที่โฮสต์หน้าเว็บจริง ก่อนเปิดใช้งานสาธารณะ

## ข้อจำกัดที่ควรรู้ก่อนต่อยอด
- Gemini เป็นโมเดลภาษา-ภาพทั่วไป ไม่ใช่โมเดลที่เทรนเฉพาะสำหรับจำแนกงูไทย ความแม่นยำขึ้นกับคุณภาพรูปและจำนวนชนิดในฐานข้อมูลอ้างอิง
- ชื่อรุ่นโมเดลของ Google เปลี่ยนบ่อยและมี breaking change ได้ ถ้าเจอ error ว่าโมเดลหมดอายุ ให้เช็ครุ่นล่าสุดที่ https://ai.google.dev/gemini-api/docs/models แล้วแก้ array `MODELS` ใน `server.js`
- ฐานข้อมูลหลักมีแค่ 10 ชนิด (เน้นงูพิษอันตรายทางการแพทย์ในไทย) งูชนิดอื่นที่ไม่อยู่ในลิสต์จะจำแนกผ่านฟีเจอร์ `extra_guess` เท่านั้น ซึ่งไม่มีข้อมูลเซรุ่ม/ปฐมพยาบาลเฉพาะเจาะจง
- คำเตือนด้านความปลอดภัย ("ไม่ใช่การวินิจฉัย", ปุ่มโทร 1669 ฯลฯ) ที่มีอยู่ในโค้ดไม่ควรถูกลบออกเวลาต่อยอด เพราะเกี่ยวข้องกับความปลอดภัยของผู้ใช้จริง
